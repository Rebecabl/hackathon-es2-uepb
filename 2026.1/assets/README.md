# Instruções para as Fotos do Evento

Deposite as fotos do hackathon nesta pasta utilizando os seguintes nomes de arquivo (formato .jpg ou .png):

1. `foto-geral.jpg`: Foto panorâmica da turma / encerramento do hackathon.
2. `primeiro-lugar.jpg`: Foto da equipe que conquistou o 1º lugar recebendo o certificado/premiação.
3. `segundo-lugar.jpg`: Foto da equipe do 2º lugar.
4. `terceiro-lugar.jpg`: Foto da equipe do 3º lugar.

Assim que os arquivos forem adicionados com esses nomes, o README principal do repositório exibirá as imagens automaticamente.

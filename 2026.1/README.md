## Classificação das Equipes

### Primeiro Lugar: AVA-UEPB (Assistente Virtual Acadêmico)

- **Equipe:** Ingridy Abrantes de Matos, Stephany Bianca Silva Lima e Vitorio Gomes de Freitas.
- **Repositório:** [ViGF/chatbot-avauepb](https://github.com/ViGF/chatbot-avauepb)
- **Problema abordado:** Atendimento da coordenação do curso de Ciência da Computação em relação a dúvidas sobre normas, formulários e calendário acadêmico.
- **Solução proposta:** Assistente virtual via WhatsApp utilizando fluxo automatizado com n8n, modelo de linguagem natural e busca em documentos institucionais da universidade.
- **Aspectos técnicos:**
  - Utilização de busca semântica em base vetorial para consulta ao regimento acadêmico.
  - Orquestração de fluxos automatizados com n8n em servidor próprio.
  - Integração com repositório de documentos institucionais para consulta de modelos e formulários.

---

### Segundo Lugar: Eventualize

- **Equipe:** Agnes Ludmila de Araújo Teixeira, Beatriz Wanderley Gomes, Cibele Diniz Felix dos Santos, Maira Fernandes Nunes e Wellington Diogo da Silva Rangel.
- **Problema abordado:** Divulgação e gerenciamento de inscrições em eventos acadêmicos da instituição.
- **Solução proposta:** Sistema web para centralizar a visualização de eventos, inscrições e gerenciamento por parte dos organizadores.
- **Aspectos técnicos:**
  - Separação entre frontend web e backend com API REST em Java e Spring Boot.
  - Especificação de requisitos orientada a normas de qualidade de software.
  - Organização do projeto orientada por quadro de atividades.

---

### Terceiro Lugar: Cantina UEPB

- **Equipe:** André Vinícius Barros Macambira, Maria Vitória da Silva Medeiros, Myllena de Sousa Medeiros e Rafael Soares Felix.
- **Repositório:** [AndreVinnis/Cantina-UEPB](https://github.com/AndreVinnis/Cantina-UEPB)
- **Problema abordado:** Filas e tempo de espera no atendimento das cantinas universitárias durante os intervalos das aulas.
- **Solução proposta:** Sistema de autoatendimento para consulta de cardápio e realização de pedidos com pagamento via PIX, organizando a fila de preparo.
- **Aspectos técnicos:**
  - Arquitetura baseada em microsserviços em Java com Spring Boot.
  - Integração com serviço de pagamentos.
  - Containerização dos componentes da aplicação com Docker.
